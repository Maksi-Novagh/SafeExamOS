# UI prototype

This directory is a **visual/interaction reference prototype**, not the production SafeExamOS shell.

Purpose:

- lock down the SEB-derived visual language early;
- validate pre-flight information hierarchy;
- give future GTK/Qt/webview/native implementations a reference;
- make UI reviews possible before boot integration.

Open `index.html` locally in a browser.

The prototype intentionally uses no external dependencies or remote assets.

See `docs/design-system.md`.
